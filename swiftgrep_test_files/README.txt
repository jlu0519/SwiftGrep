SwiftGrep Test Corpus

This folder contains files designed to test:
- Basic text matching
- Case-sensitive and case-insensitive searches
- Multiple matches in one file
- Recursive directory searches
- Empty files and directories
- Lines with spaces, tabs, punctuation, and Unicode
- Files that do not contain the search term
- Binary-file handling
